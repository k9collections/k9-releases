## Why use K9?

Managing several Roblox accounts gets repetitive. K9 puts your saved accounts, launch controls, and preferences together, so you can spend less time setting things up each session.

| What you can do | How it helps |
| --- | --- |
| **Organize your accounts** | Keep accounts together with groups, search, and a main-account selection. |
| **Queue multiple launches** | Select accounts once and launch them in sequence, with spacing as low as one second. |
| **Join a player by username** | Send selected accounts a request to join a player's available game. |
| **Join your main account** | Quickly send other selected accounts to your main account's game. |
| **Save destinations** | Keep favorite places and supported server links ready for your next session. |
| **See account presence** | Check whether Roblox reports an account as online or in a game. |
| **Make it your own** | Choose themes, accent colors, layouts, and a faint custom background image. |
| **Keep your setup across updates** | Update the same app while retaining saved accounts and preferences. |

**About multiple accounts:** K9 queues launch requests for several accounts. Roblox controls whether multiple game windows stay open and whether a join succeeds. Player privacy, server availability, and session validity can affect joining. K9 does not bypass Roblox's client restrictions or promise undetectability.

## Your data stays on your PC

- Saved account sessions and optional saved passwords use Windows encryption.
- A K9 password locks access to the app, with optional remembered access.
- A one-time recovery code can reset your **K9 lock password** without removing saved accounts. Set it up before you need it and store it outside K9.
- Account details, passwords, cookies, and recovery codes are not uploaded to this repository. K9 contacts Roblox for account features and GitHub for updates.

## Get started

1. Open **[Download the latest K9](https://github.com/k9collections/k9-releases/releases/latest)**.
2. Under **Assets**, download **K9-Setup-VERSION.exe**. The `.blockmap`, `latest.yml`, and source archives are not the installer.
3. Run the installer and open **K9** from your desktop.
4. Create your K9 password and save the recovery code somewhere safe.
5. Add your Roblox accounts, select the ones you want, and choose a destination.

You need **64-bit Windows** and **Roblox Player** installed to launch games. The current installer is unsigned, so Windows may display an unknown-publisher notice.

## Updates without starting over

Enable **Automatically check and download updates** in Settings. K9 checks at startup after unlocking and periodically while unlocked. When an update is ready, choose **Restart and update**.

You can also use **Settings → Check for updates**. Your friend can use the same release page and updater; each person keeps their own saved accounts and chooses when to restart.
